## Defects and fixes

### Optional summaries must not discard valid facts (`23e9d72`)

A spoken project turn completed, but its optional digest failed provenance/compression validation and rejected the entire learning update. A deterministic regression pairing a valid source-grounded fact with an invalid optional digest reproduced the error. The original ephemeral model response was not logged, so its exact rejected summary is unavailable.

The worker now skips an invalid optional digest, reports that it was not saved, and sends fact proposals through the unchanged strict evidence, policy and revision checks. Shared digest validation rejects unknown/duplicate/provisional/summary sources and oversized or uncompressed content. Invalid fact evidence still rejects the proposal; valid summaries are preserved. The regression fails before the fix and passes afterward. The authenticated native worker test and rebuilt live voice/UI path also pass.

Review wording now says Repeated by you instead of implying separate conversations. Tidy no longer claims that background summaries finished before their check completes.

### Project category must not depend on key word order (`fd980d6`)

The real confirmed project had semantic key `garden_birdhouse_project`, while discovery only recognised `project_` at the start. No check-in appeared across the expected background ticks. After closing the disposable app, a read-only inspection of its stored metadata established that mismatch.

Discovery now recognises complete category words separated by underscores or dots in any key position. The regression fails on the actual suffix key before the fix, passes afterward, and rejects unrelated substrings such as projection and goalkeeper. Confirmed-source checks and per-item permission remain unchanged. Rebuilt native discovery, Snooze, Dismiss and Allow/OS-speech delivery passed.

## Limits

Two fixtures were misheard by STT: peppermint as lemon, and fruit as food. Incorrect speech recognition was not counted as correct corroboration or as proof of the intended fact. Fresh mango retention was verified against the actual transcribed source. A short post-cue reaction gap and fresh readiness checks improved test staging; memory cannot automatically repair an incorrect transcript.

Fresh/background windows initially lacked fresh animation telemetry; raising/observing the app restored it. Those observations alone were not counted as metered-playback passes; later targeted voice flows did include metered Speaking and a return to idle/wake listening.

These bounded macOS tests do not establish weeks of learning quality, every accent/conflict/sensitive-data pattern, Windows/Linux native acceptance or full VoiceOver coverage. Existing automated storage, capacity, cancellation and adversarial tests remain complementary. No new demo was recorded.
