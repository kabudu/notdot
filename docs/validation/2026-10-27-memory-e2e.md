## Interpretation and limits

One immediate post-cue fixture was transcribed as lemon rather than peppermint. It was not counted as correct corroboration. The learner kept the changed claim provisional; subsequent clear utterances and native review established the intended state. The harness now leaves a short reaction gap after activation and requires a fresh readiness snapshot after restart. Model memory cannot repair an incorrect transcript automatically.

Fresh/restarted background windows initially lacked fresh animation telemetry; raising/observing the app restored it. Those observations alone were not counted as metered-playback passes. The later combined recall turn did include metered Speaking and a return to idle/wake listening.

These are bounded macOS acceptance tests, not evidence for weeks of learning quality, arbitrary accents, every conflicting statement or every sensitive-data pattern. Existing automated storage, cancellation, capacity, security and adversarial live-model tests remain complementary. Windows/Linux native memory UI and OS speech are separate platform gates. No fresh demo was recorded.

## Reliability finding and remediation

A later spoken birdhouse-project turn completed normally, but the learner reported that its optional digest failed provenance/compression validation. The whole proposal was rejected before any fact could be saved. A deterministic regression pairing a source-grounded fact with an invalid optional digest reproduced the same error. This establishes the failure mechanism; the original ephemeral model response was not logged, so the exact rejected summary is unavailable.

The worker now drops an invalid optional digest, reports that it was not saved, and applies the fact proposals through the unchanged strict source/policy/revision checks. Digest validation is shared with the strict storage boundary; unknown, duplicate, provisional and summary sources, oversized/uncompressed content remain rejected. Invalid fact evidence still rejects the proposal. Valid summaries are preserved. The regression fails before this fix and passes afterward. Full local CI passes; the authenticated native queue → actual Terra → persisted-note test also passes after the fix. Native voice/UI acceptance of the rebuilt fix remains pending.

Two wording issues found in Review were also corrected: corroboration now says Repeated by you (separate turns do not require separate chats), and Tidy no longer claims background summaries are finished before their check completes.
