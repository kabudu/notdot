Ask your own notdot companion to look up current information, work in a separate browser or use approved Mac apps.

- **Live web search.** Turn on current web results in Settings for your own companion.
- **Browser Use.** Open sites, switch tabs and interact in a separate browser on macOS, Windows and Linux, with approval for new sites and sensitive actions. An installed Chrome, Chromium, Edge or Brave is required.
- **Computer Use (preview).** Read and press controls in approved apps on macOS, Windows and Linux. macOS requires Accessibility permission.
- **Screenshots and spoken approvals.** Approve browser screenshots and Mac window captures individually, or answer a permission prompt by voice.
