Start with a clean slate?

Delete every saved memory, unconfirmed note, summary, older memory record, reminder and suggestion from this computer. notdot will restart with a new chat.

Your settings and saved key stay as they are. Old chats remain in Codex / ChatGPT history, but notdot will start a fresh chat. Backups and other copies are not erased.

How to use the orb
